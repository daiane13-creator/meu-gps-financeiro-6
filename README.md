# Meu GPS Financeiro 6.0

Versão profissional em React + Vite + Tailwind, preparada para publicar na Vercel e instalar no iPhone como PWA.

## O que está incluso

- Dashboard financeiro
- Contas
- Cartões
- Transações
- Parcelamentos
- Orçamentos
- Metas
- Investimentos
- Calendário financeiro
- Assistente financeiro demonstrativo
- Backup JSON
- Exportação CSV
- Manifest PWA para instalação no iPhone
- Estrutura preparada para Firebase

## Como rodar localmente

```bash
npm install
npm run dev
```

Depois abra o endereço exibido no terminal.

## Como publicar na Vercel

1. Suba esta pasta para um repositório no GitHub.
2. Acesse https://vercel.com.
3. Clique em Add New Project.
4. Selecione o repositório.
5. Clique em Deploy.

## Como instalar no iPhone

1. Abra o link da Vercel no Safari.
2. Toque em Compartilhar.
3. Toque em Adicionar à Tela de Início.
4. Toque em Adicionar.
